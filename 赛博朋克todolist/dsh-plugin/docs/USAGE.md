# 赛博朋克 · Todo list 使用说明（攻略版）

> 一句话：右下角一颗绿色 HUD 球，点开就是你的任务面板。每勾一个任务 = 一次击杀，掉经验、涨等级、连击翻倍。

---

## 1. 找到它

- 固定在网页右下角，默认位置 **右 24 / 底 84**（在番茄钟上方一点，避免撞车）。可任意拖动，位置会记住。
- **收起时**：外圈绿色进度环 = 当前等级的经验进度；中间数字 = 待办数量。
- **有逾期任务时**：环会脉冲发光、数字变黄、下方出现一个 `!`。

## 2. 展开 / 收起

- 单击球体展开；点右上角 `−` 或点标题栏收起。
- 展开状态同样会记住，下次刷新恢复。

## 3. 添加任务

1. 在输入框里打字，**回车**即添加。
2. 想带截止时间？先在输入框下方选好：`无` / `2小时` / `今晚` / `明天`，下一条任务自动带上。
3. 空的回车不会添加，只会让输入框抖一下（防误触）。

## 4. 核心循环：打怪升级

| 动作 | 结果 |
| --- | --- |
| 点圆形复选框 | 击杀：掉经验、播放音效、弹 `+25 XP` 浮字 |
| 2 分钟内连续击杀 | 连击成立，倍率从 ×1.0 升到 **×2.0 封顶**（每次 +0.25） |
| 经验攒满 | 升级：全屏 `LEVEL UP · LV n` + 上行音阶，标签页等级 +1 |

**经验数值**：P0 = 10 · P1 = 15 · P2 = 25 · P3 = 40，再乘连击倍率。
**升级门槛**：120 × 当前等级（等级越高越难升，这是刻意的）。
**反刷机制**：同一个任务「完成 → 撤销 → 再完成」不会重复给经验（只认首次击杀）。

## 5. 优先级与截止时间

- **优先级**：点任务右侧的 `P1/P2/P3` 标签循环切换（→ 无 → P1…）。优先级越高经验越多、排序越靠前。
- **截止时间**：点任务上的截止标签循环切换：`无 → 2小时 → 今晚21:00 → 明天21:00 → 无`。
- **逾期**：过了截止时间的任务自动排到最前，标签变黄显示「已逾期 3h」，圆球同步报警。

## 6. 编辑 / 删除 / 过滤 / 清空

- 鼠标悬停任务行 → 出现 `✎`（编辑）和 `×`（删除）。编辑时回车保存、Esc 取消。
- 顶部 `ALL / ACTIVE / DONE` 切换过滤。
- 底部 `PURGE DONE` 清空已完成——**要点两次**（第一次变「确认清除？」），3 秒不点自动取消。

## 7. 音效

- 击杀一声「叮」，连击越高音越尖；升级是四音阶的小火箭。
- 底部 `♪` 按钮开/关音效，状态会被记住。
- 浏览器要求先点过页面才允许出声（系统限制，不是 bug）。

## 8. 数据与隐私

- 任务与经验保存在本机：`C:\Users\<你>\.dsh\storages\neon_tasks.json`。
- 刷新、重启 DSH 都不丢。
- 宿主不可用时自动切到浏览器本地副本，状态行显示「仅本地」。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| 刷新后没出现 / 还是旧样式 | 重启一次 DSH（模块代缓存） |
| 没声音 | 检查 ♪ 是否被静音；先点一下页面 |
| 两个窗口同时打开 | 后保存的覆盖先保存的（单窗口无影响） |
| 字体不是苹果方体 | 苹果设备显示 SF Pro；Windows 回退 Segoe UI / 微软雅黑加粗（SF Pro 不能随插件分发） |

## 10. 已知边界

- 窗口高度低于约 500px 时任务列表会被压缩（有 140px 下限）。
- 球体浮在页面最上层，可能与你其他悬浮组件重叠——拖开即可。
